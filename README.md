# SendSize

Simple Android app for compressing and converting files.

## Features

### Compression

* Compress videos
* Compress images
* Target size mode (MB)
* Percentage compression
* Quality priority mode
* Exact target size mode

### Conversion

* Video conversion
* Audio conversion
* Image conversion
* Extract audio from videos
* Remove metadata
* Remove audio from videos

### UI

* Material 3
* Material You support
* Dynamic colors
* Smooth animations
* Compression history
* Haptic feedback

## Built With

* Kotlin
* Jetpack Compose
* Material 3
* FFmpeg

## Download

Build the project using Android Studio.
